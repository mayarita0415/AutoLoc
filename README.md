# AutoLoc

## Acteurs

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Cas d'utilisation

### Client
- Consulter les véhicules disponibles
- Rechercher un véhicule
- Réserver un véhicule
- Consulter ses réservations
- Annuler une réservation

### Agent d'agence
- Gérer les réservations
- Gérer les clients
- Gérer les véhicules
- Enregistrer une location
- Enregistrer un retour de véhicule

### Responsable d'agence
- Consulter les statistiques
- Gérer les agents
- Superviser les activités de l'agence

### Administrateur
- Gérer les utilisateurs
- Gérer les agences
- Gérer les véhicules
- Gérer les comptes
